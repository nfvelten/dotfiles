# User commands

These scripts are installed into `~/.local/bin` by GNU Stow.

## Desktop

- `dynamic-wallpaper` — select the wallpaper for the current time
- `desktop-screenshot` — capture a window, region or full screen
- `desktop-clipboard` — open clipboard history
- `scratchterm` — toggle a terminal scratchpad
- `scratchwork` — toggle the work scratchpad
- `scratchspotify` — toggle the Spotify scratchpad
- `scratchtmux` — toggle the tmux and Org scratchpad
- `scratchpad-center` — center a scratchpad window
- `librewolf-themed` — launch LibreWolf with the current theme

## Work

- `comercial-api-start` — start the commercial API workspace
- `meeting-record` — record a meeting
- `meeting-transcribe` — transcribe a recording
- `video-note` — create a note from a video
- `habit-tracker` — update habits
- `semanal-auto` — update the weekly note
- `open-board-item` — open a board item

## Development

- `cg-search` and `cg-callers` — search code and callers
- `hyprlock-art-sync` and `hyprlock-track` — maintain lock screen art

Scripts that belong to a project live in that project. This directory only
contains commands exposed as part of the user environment.
